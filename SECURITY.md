# Security Policy

## Supported versions

Only the latest `Unreleased` development line is actively maintained until a tagged release exists.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use GitHub's private security advisory flow for this repository, or contact the repository maintainers privately through the email listed on the GitHub profile.

Please include:

- A clear description of the issue.
- A minimal reproduction or affected API.
- Impact and any required Roblox permissions.
- A suggested mitigation if you have one.

Do not include credentials, session data, or private player information in a report.
